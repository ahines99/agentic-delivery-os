# Security reporting and current scope

This repository is a local foundation. It does not yet execute target repository code or
provide authenticated external integrations. Its structural policy checks are not a deployed
security boundary. Read [the threat model](docs/security-model.md) before adding execution.

Do not put credentials, private repository contents, or exploit payloads with secrets into
public issues. A public security contact/private reporting channel must be configured by the
repository owner before a connected public release. Until then, report privately to the
maintainer through an existing trusted channel.

No version is currently represented as production-hardened or suitable for hostile multi-tenant use.
